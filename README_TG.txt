ALMAZ SHOP — Дастури оғоз

1) Node.js LTS насб кунед.
2) Папкаи лоиҳаро кушоед.
3) Дар дохили папка PowerShell кушоед.
4) Фармон: npm.cmd install
5) Фармон: Copy-Item .env.example .env
6) Файли .env-ро бо notepad .env кушоед ва ADMIN_PASSWORD ва SESSION_SECRET-ро бо арзишҳои қавии худ иваз кунед. ADMIN_USER=muso мемонад.
7) Фармон: npm.cmd start
8) Сайт: http://localhost:3000
9) Панели админ: http://localhost:3000/admin

Маълумот дар data/store.json нигоҳ дошта мешавад. Бастаҳо, нархҳо ва фармоишҳо аз сервер идора мешаванд ва байни браузерҳои ба ҳамин сервер пайвастшуда умумӣ мебошанд. Барои версияи истеҳсолӣ/интернетӣ hosting, HTTPS, базаи боэътимод, нусхаи эҳтиётӣ ва чораҳои иловагии амниятӣ лозиманд. Ҳоло пардохти онлайн пайваст нест.

Агар сервер аллакай фаъол бошад, дар PowerShell Ctrl+C пахш кунед, баъд npm.cmd start иҷро кунед.
